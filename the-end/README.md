# Site Giovanna Derani

## Estrutura
- `index.html`
- `css/style.css`
- `js/script.js`
- `img/`

## Como abrir
Abra o arquivo `index.html` no navegador.

## Como publicar
Envie o conteúdo desta pasta para o GitHub Pages, Cloudflare Pages, Netlify ou para a pasta `public_html` de uma hospedagem.

## Observação
Os efeitos respeitam a preferência de acessibilidade `prefers-reduced-motion` e são reduzidos automaticamente em telas menores.
